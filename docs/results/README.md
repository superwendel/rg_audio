# Benchmark data

The [performance guide](../performance.md) explains the results and their
limits. The datasets below retain timings, quality metrics, hashes, and raw
trials needed to inspect the comparisons.

| Dataset | Scope |
| --- | --- |
| [2026-09-26](2026-09-26-mono/README.md) | Current RGS/QOA decode comparison, including mono/stereo breakdowns |
| [2026-09-25](2026-09-25/README.md) | Codec size and quality, earlier timing results, and game-workload measurements |

Metadata uses repository-relative source paths and dependency identifiers,
omitting local installation and invocation details. Measurement values and content hashes are
unchanged. Corpus audio is not redistributed here; see the manifest and
[reproduction guide](../benchmarks.md).
